This is my personal portfolio website showcasing my projects, skills, and experience as a software developer.

## Features

- Interactive terminal-styled introduction
- Project showcase with links to demos and source code
- Skills section with proficiency ratings
- About me section
- Contact information
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- P5.js for background effects

## Project Structure

- `index.html` - Main webpage
- `style.css` - Styling for the portfolio
- `script.js` - JavaScript functionality
- `ai-background.js` - Background animation effects
- `images/` - Project screenshots and icons
